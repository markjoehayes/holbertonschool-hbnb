# HBnB Frontend

This repository contains the **frontend portion** of the HBnB project. It includes static HTML, CSS, and JavaScript files that represent the user interface of the application. This submission is **independent from any backend** and serves as a standalone prototype of the final product’s layout and interactions.

---

## ✨ Overview

This frontend showcases:

* The main HBnB landing page
* Individual place pages
* A login page
* A review submission form
* Icons, layout design, and styling
* Basic client-side interactions (no data persistence)

This project focuses strictly on the **UI/UX layer**, with no backend API connection.

---

## 🎨 Features

### ✔ Static Pages

* **index.html** – Main listing page
* **place.html** – Detailed place page
* **login.html** – Login form
* **add_review.html** – Review submission form

### ✔ Style & Icons

* Organized and clean layout using **styles.css**
* Includes custom icons and images under `/images`

### ✔ JavaScript

* Basic DOM interactions via **scripts.js**
* Placeholder functionality for future backend integration

---

## 🚀 How to Run

No installation required.

1. Download or clone this repository.
2. Open `index.html` in any web browser.

Alternatively, run a simple local server:

```bash
python3 -m http.server
```

Then visit:
**[http://localhost:8000](http://localhost:8000)**

## 📌 Notes
